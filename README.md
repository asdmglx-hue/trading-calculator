# Trading Quantity Calculator

USDT position-size calculator for martingale-style recovery sizing, with live Binance Futures `1000PEPEUSDT` price and a 15-minute volatility level badge.

## Open

Open `quantity-calculator.html` in a browser (double-click or drag into Chrome).

## Features

- Lot / USDT size from Total Loss, Desired Profit, Entry, Take Profit
- Live price and 24h change (Binance Futures WebSocket)
- Volatility: Very Low / Low / Medium / High (closed 15m candles + live spike detect)
- Next 15-min candle countdown (PKT)
